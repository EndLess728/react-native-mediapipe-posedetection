## Install

```bash
npx expo install react-native-mediapipe-posedetection react-native-vision-camera react-native-worklets-core
```

Then follow the [installation guide](getting-started/installation/) to add a model file and enable frame processors.

## Good for

Fitness and workout apps, rep counters, yoga and posture feedback, physiotherapy tools, sports form analysis, motion-controlled games and AR effects.
